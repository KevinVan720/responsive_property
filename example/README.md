# responsive_property example

Examples of the [responsive_property](https://pub.dev/packages/responsive_property)
package. Resize the window (or rotate the device) to see them adapt:

- **Responsive Int** (`lib/responsive_int.dart`): a grid with 2, 4 or 6
  columns on mobile, tablet and desktop screens.
- **Responsive Flex** (`lib/responsive_flex.dart`): a Flex that is vertical on
  mobile and tablet screens and horizontal on desktop screens.
- **Responsive Builder** (`lib/responsive_builder.dart`): a `ScreenBuilder`
  with a different layout for mobile, tablet and desktop screens.

Run it with `flutter run`, for example `flutter run -d chrome`.
